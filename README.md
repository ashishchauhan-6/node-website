# Simple Node.js Website

A small responsive website using Node.js, Express, HTML, CSS, and browser JavaScript.

## Run it

Install Node.js, then from this folder:

```bash
npm install
npm start
```

Open http://localhost:3000.

For automatic restarts while editing (Node.js 20.11+):

```bash
npm run dev
```

The site is served from `public/`. The example API endpoint is `GET /api/message`.
